October 22, 2026 a48afe5

  • Added niches/haunted-wiki/note-generator.html and .js, a vanilla-JS form with JSON export and import (versioned schema, keyed checklists), live Markdown generation using Chicago-style notes and bibliography with UTC-safe date formatting, and two print modes (a worksheet print, plus a body.print-note mode rendered with marked). Printed text is copied into mirror elements so long entries don’t get cut off.
  • Added patch-notes/ page and a .footer-link in .footer-controls across all 20+ footers, including the two Next.js apps.
  • Changed patch-notes/ split into General, Therapists, and Tech panels using the ARIA tabs pattern (role="tablist"/tab/tabpanel, roving tabindex, Arrow/Home/End keys). Each tab has its own link via #general, #therapists, #tech (history.replaceState), and scroll-margin-top keeps the panel clear of the sticky nav. Without JS the panels show stacked with the tablist hidden, and print shows all panels. The script is a small inline IIFE with no dependencies.
  • Changed assets/site.css no longer sets a default background-image on body. Pages are plain (--bg-main) by default, and hubs opt in with the linear-gradient(var(--overlay-color)…), url('./*.jpg') override. Home now declares stacked-logs.jpg explicitly.
  • Added assets/favicon.jpg (128×128, center-cropped), linked as <link rel="icon" href="/assets/favicon.jpg"> on all static pages. In My Budget, metadata.icons is set and the app’s favicon.ico removed, then the app was rebuilt and its export re-synced.
  • Added authors-library/feather.jpg and therapist-tools/robin.jpg. All new images were passed through magick -strip, which removed EXIF metadata, including GPS from the original phone photo.
  • Fixed <body aria-label> text on 10 pages that still described a firewood-logs background they no longer show.
  • Changed Footer disclaimer copy updated in all static pages and in the layout.js files. The my-budget and magicrpg static exports were rebuilt and re-synced from out/.
  • Fixed Resources .layout-wrapper changed from flex-wrap to a 260px minmax(0,1fr) grid. The table’s min-content width was forcing the main column to wrap below the sticky sidebar. Also added overflow-wrap:anywhere on cells and a stacked layout at 800px and below.
