Insurance Superbill Generator

How to use this tool▾
  1. Fill in the provider, client, and insurance details.
  2. Add each service with its date, CPT code, diagnosis codes, and fee. Totals add up for you.
  3. Generate the superbill, check it, then print it for your client.

Saving your work: Nothing saves on its own. Use Save .json to keep your entries and Import .json to load them next time.

Tip: Save a .json file so next month’s superbill only needs new dates.

Import, save, print, and clear are in the tool menu.
